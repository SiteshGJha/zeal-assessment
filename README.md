# Customer Entitlement & Support Case Platform API

Internal platform API and MCP Server providing a unified customer entitlement and support case view across Salesforce, NetSuite, and Snowflake for traditional integrations and AI agents.

## Project Structure

```
.
├── openapi.yaml           # OpenAPI 3.1 specification (Part A)
├── src/                   # Platform API service (Part B)
├── tests/                 # Unit, integration, and contract tests
├── mcp/                   # Model Context Protocol server for LLM agents (Part C)
├── postman/               # Postman collection and environment
├── docs/plans/            # Specification and task planning
├── DECISIONS.md           # Architecture trade-offs and rationale
├── SECURITY.md            # Security, governance, and guardrails
├── TESTEVALS.md           # MCP evaluation scenarios and results
└── AI_USAGE.md            # AI assistant usage log and verification
```
